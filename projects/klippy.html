Software / Personal build

Long video.
Usable clips.

KLIPPY brings transcription, clip selection, and captioned exports into a focused editing workflow.

The workflow

  1. Transcribe a longer video with Whisper.
  2. Review suggested clips or select an excerpt through its transcript.
  3. Edit the selection, add captions, and export.

Built around a specific job

This is a personal build made with Claude Code and Codex. The goal was to help a content creator turn longer footage into usable captioned clips.

Availability

A public demo and source repository are not linked yet. The original build post describes the project and its features.
